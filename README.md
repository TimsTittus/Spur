# Spur

A free impromptu speaking practice tool. Pick a category, hit Spin, and talk about whatever comes up.

## How it works

1. Choose a category from the home page
2. Hit **Spin** — a random topic animates in
3. Speak. Spin again whenever you're ready

There's also a built-in 1-minute timer if you want to keep yourself honest.

## Categories

Everyday Life · Technology · Food and Culture · Philosophy and Life · Pop Culture · Travel and Places · Sports and Fitness · Science and Nature · Relationships · Work and Career · History and Society · Money and Finance · Art and Creativity · Weird and Hypothetical · Psychology and Mind

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion)
- Topics stored as plain MDX frontmatter — no database

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
